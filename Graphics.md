For building JavaScript applications with a desktop application quality UI, the best options are comprehensive UI component libraries designed for enterprise-level applications, such as Ant Design, Mantine, or Sencha Ext JS, used in conjunction with a modern framework like React or Vue.js. 
Key Recommendations
These libraries provide the complex, feature-rich components (like robust data grids, pickers, and layout managers) needed to achieve a professional, high-performance desktop application feel. 
Ant Design: Developed by Alibaba, it offers a clean, elegant, and comprehensive set of enterprise-level React UI components known for their professional design.
Mantine: A fully-featured React UI library providing an extensive collection of components (100+) and hooks, known for high customizability, great developer experience, and good performance with modern styling methods.
Sencha Ext JS: Specifically designed for enterprise applications, Ext JS offers a massive, comprehensive component library (grids, charts, etc.) and robust data handling capabilities, ideal for complex, sophisticated web applications that need a true desktop feel. This is often a commercial product for full features.
React Suite: Another excellent option built for enterprise systems using React, offering a solid range of components with a clean aesthetic. 
Core Frameworks for Desktop Experience
The "desktop quality" look and feel often depends heavily on a rich set of integrated components. Most modern solutions leverage core frameworks like React or Vue.js for their underlying structure and performance: 
React: A dominant library for building UIs, with a vast ecosystem of accompanying UI libraries (MUI, Ant Design, Mantine, etc.) that can deliver a high-quality user experience.
Vue.js: A progressive framework with excellent UI libraries like Quasar and Vuetify that are also capable of building high-performance, responsive applications that can feel native.
