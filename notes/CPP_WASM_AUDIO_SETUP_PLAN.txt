-----------------------------
- Enable SIMD: -msimd128 flag (autotune, FFT speedup)
- Enable WASM threads: -pthread flag (parallel resonance analysis)
- Optimization level: -O3 for production, -Oz for size
- Pre-allocate audio buffers (avoid runtime allocation)
- Use AudioWorklet for real-time autotune/tempo

3.2 Memory Management (CRITICAL - 1GB LIMIT)
---------------------------------------------
- Initial memory: -s INITIAL_MEMORY=16MB (conservative start)
- Allow growth: -s ALLOW_MEMORY_GROWTH=1
- Maximum memory: -s MAXIMUM_MEMORY=512MB (leave room for browser)
- Use fixed-size ring buffers for real-time processing
- Avoid memory growth during audio processing (causes glitches)

3.3 JavaScript Integration
---------------------------
- Emscripten embind for C++ ↔ JS bindings
- Export ONLY needed functions (reduce WASM size)
- Use cwrap for simple pitch/tempo functions
- AudioWorklet processor for real-time autotune

- Strip debug symbols: -s ASSERTIONS=0 in production

JUCE vs Lightweight Libraries:
-------------------------------

Advantages of JUCE:
+ Professional-grade code quality
+ Comprehensive documentation and community
+ Used in real DAW products (proven in production)
+ Integrated ecosystem (audio + MIDI + parameters + presets)
+ AudioBuffer abstraction (cleaner than raw float arrays)
+ Built-in effects and processing blocks
+ Plugin architecture (modular design patterns)

Disadvantages for WASM:
- Larger binary size (~100MB source, varies in compiled size)
- Some features need platform adaptation (GUI, file I/O)
- Requires C++17 (not an issue with modern Emscripten)
- More complex build process than single-file libraries
- AGPLv3 license (commercial license available)

When to Use JUCE:
- Building complex audio applications with multiple components
- Need professional plugin-style architecture
- Want battle-tested DSP algorithms
- Planning to port to native desktop later
- Comfortable with larger bundle size for better code structure

When to Use Lightweight Libraries Instead:
- Minimal bundle size is critical (<1MB)
- Simple, focused tools (one feature only)
- Learning DSP from scratch (simpler code to read)
- Very specific algorithm not in JUCE

JUCE + Other Libraries Strategy:
---------------------------------
You can mix JUCE with other libraries:
- Use JUCE AudioBuffer with aubio pitch detection
- Use JUCE DSP filters + SoundTouch time-stretching
- Use JUCE audio graph + KissFFT for custom spectral processing
- Wrap lightweight libraries in JUCE AudioProcessor interface
